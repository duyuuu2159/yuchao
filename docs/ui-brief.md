# 鱼巢界面改版任务书

这是改版前写给自己的任务说明：先把问题和标准写清楚，再动手。改完后逐条对照检查。

## 这个界面是给谁用的

一个同时用四五个 AI agent 的人，每天打开它做三件事：找回某次对话、看看有没有新泄露的密码、看看服务器和配置是否正常。也会被面试官打开看 30 秒。所以它要在 5 秒内说明「这是什么、现在一切是否正常」，并且经得起日常反复使用。

## 现在的问题（按严重程度）

1. **顶栏塞了所有东西。** 品牌、5 个页签、搜索框、agent 筛选、两个复选框、更新索引按钮挤在一行，窄一点就折成两行。搜索和筛选只对「会话」页有用，却在每个页面都显示。
2. **没有首页。** 五个功能各自一页，打开后直接是会话列表，看不出这个工具能做什么，也没有一处能回答「现在一切正常吗」。
3. **对话正文是纯文本。** agent 的回复全是 Markdown，代码块、行内代码、标题、列表都没有渲染，长回复很难读。
4. **五个页面像五个人写的。** 页面宽度、标题大小、有没有标题、提示文字的位置都不一致。
5. **会话列表是一长串。** 一千个会话没有按日期分组，agent 标签是四种颜色的实心色块，比标题还抢眼。
6. **刷新就丢位置。** 当前页面和打开的会话没有写进地址，刷新后回到起点，也没法把某个会话的链接发给别人。
7. **只能跟随系统的明暗模式**，不能手动切换。
8. **加载中只有三个字**，页面会跳动。
9. **命令提示写的是 `node src/cli/main.ts ...`**，用 exe 的人看不懂，也不能一键复制。

## 要做成什么样

**框架**
- 左侧固定导航栏：品牌、六个入口（概览、会话、安全扫描、画像、配置、服务器），每项带图标。底部放全局操作：更新索引（带上次结果）、显示原文、明暗切换。
- 窗口窄于 900px 时导航栏收成只有图标的窄条；窄于 720px 时会话页的列表和正文一次只显示一个。
- 每个页面用同一种页头：标题、一句说明、右侧放该页自己的操作。正文最大宽度统一。
- 搜索框、agent 筛选、「含工具调用」只属于会话页。

**概览页（新增，作为首页）**
- 一行数字：会话总数、消息总数、时间跨度、agent 数量。
- 四张状态卡片，每张回答一个问题并能点进去：泄露的秘密（高危几个）、配置文件（几个正常、几个损坏或有未记录的修改）、服务器（是否正常、磁盘）、各 agent 的会话数。
- 最近的会话。
- 状态用「图标 + 文字」表达，颜色只做辅助。数字和标签用正文颜色，不用状态色给整块上色。

**会话页**
- 列表按日期分组（今天、昨天、本周、更早按月），分组标题吸顶。
- agent 标签改成「小圆点 + 名字」的浅色标签，不抢标题。
- 正文渲染基础 Markdown：代码块（带语言名和复制按钮）、行内代码、粗体、标题、列表、链接只显示文字不可点（内容来自 agent，不可信）。不引入第三方库，自己写一个小的、只生成 React 节点的渲染器，不用 `dangerouslySetInnerHTML`。
- 搜索命中的词在渲染后仍然高亮。
- `/` 或 `Ctrl+K` 聚焦搜索框。

**全局**
- 页面和打开的会话写进地址（`#/sessions/<id>`），刷新和前进后退都正常。
- 明暗模式：跟随系统、浅色、深色三选一，记在 localStorage；在页面渲染前就设置好，避免闪一下。
- 加载时显示骨架占位。
- 命令提示统一写成 `yuchao ...`，带复制按钮。
- 设计规范：一套间距（4 的倍数）、三种圆角、五级字号，全部用 CSS 变量；颜色只定义在一处，浅色深色各一份。
- 键盘可用：所有可点的东西都能用 Tab 到达，焦点有清晰的轮廓。

## 不做什么

- 不引入 UI 组件库、CSS 框架、图标库、Markdown 库。现在打包后 JS 只有 80 KB（gzip），这是一个值得保持的数字。
- 不改后端接口的行为。概览页只用已有的接口拼出来。
- 不加动画，除了 150ms 以内的悬停和焦点过渡；尊重「减少动态效果」的系统设置。
- 不改已有的安全约束：网页仍然只读，回滚、生成画像仍然只能在命令行执行。

## 怎样算做完

- [ ] 六个页面在浅色、深色下都逐页看过，没有看不清的字和错位
- [ ] 窗口宽 740px 和 1280px 都能正常使用
- [ ] 刷新页面后停在原来的页面和会话
- [ ] 从搜索结果、扫描结果、画像出处点进会话，仍然能定位到那条消息
- [ ] Markdown 渲染器有测试：代码块里的内容原样保留；恶意内容（`<script>`、`javascript:` 链接）不会变成真正的标签或可点的链接
- [ ] `npm run typecheck`、`npm test` 通过；gzip 后的 JS 不超过 100 KB
- [ ] 重新打包 exe，放到桌面

# 第二版：和个人网站一个风格，再加一个真正常用的功能

## 风格从哪里来

直接从 duyuuu.com 的页面上读出计算后的样式，而不是凭印象：

| 元素 | 网站上的值 | 鱼巢里的用法 |
|---|---|---|
| 正文墨色 | `#0f2231` | 标题、正文、深色主按钮 |
| 品牌蓝 → 天蓝 | `#0a7aa1` → `#2aa6cb` | 强调色、图表、链接 |
| 樱粉 | `#d2648b` | 只做点缀：标题末尾的句号、小标签上的短线、悬停的柱子 |
| 渐变标题 | `linear-gradient(100deg, #0a7aa1, #2aa6cb 45%, #d2648b 115%)` | 概览页大标题第二行 |
| 玻璃导航 | 白色 0.64→0.34 渐变、白色描边、`0 18px 55px rgba(31,66,120,.12)` 阴影、24px 圆角 | 侧栏、卡片、列表、阅读区 |
| 夜间背景 | `135deg #0f0b2e → #1a1145 → #0d1b3e` 的紫蓝夜空 | 深色模式背景 |
| 按钮和导航 | 全部是胶囊形；当前页是 `rgba(10,122,161,.11)` 的浅蓝底 | 同样 |
| 杂志感 | 「第 187 期 · 2026.11.10 · 星期二」刊头、「00 · 此刻」小标签、编号目录、粉色短线 + 小字栏目名 | 概览页刊头、每页的小标签、侧栏编号、卷首语和本期目录 |

网站背景用的是二次元插画，鱼巢不搬图片：一是版权，二是工具界面要的是读得清楚。用天空色的径向渐变代替，玻璃面板的不透明度比网站高，保证正文对比度。

## 新功能：接力

**问题**：用户在 Claude Code、Codex、WorkBuddy、DeepSeek 之间来回切换，常见原因是额度用完（会话里出现过「Credits 不足」「我一句你好五毛钱」）、上下文太长、或者想换个模型。每次切换都要把前因后果重新讲一遍。

**做法**：选一个会话，鱼巢在本地整理出一份交接说明，复制后粘贴给另一个 agent：
- 最初的目标、后来补充的要求（去掉「继续」「好的」和重复的话）
- 改过的文件（按最近改动排序，因为那才是现场）
- 最近执行的命令、最近遇到的报错
- 上一个 agent 最后说的话
- 开头一段写给接手 agent 的指引：先复述理解再动手、不要重做已完成的部分、先读 AGENTS.md / CLAUDE.md

**约束**：不调用大模型、不花钱；默认打码；超出长度时按重要程度逐级缩短；入口在会话阅读区和概览页「从这里开始」；命令行 `yuchao handoff latest --to codex`。

## 怎样算做完

- [ ] 六个页面浅色、深色都看过，正文对比度足够
- [ ] 接力：四家 agent 的真实会话都能整理出文件、命令、报错；Write 写入的内容里碰巧有补丁格式文字时不误判
- [ ] 测试覆盖接力的提取规则和打码
